    How to

    From Grid 3 to a smaller grid set in three steps.

    1. 1

      Export your grid set from Grid 3

      Save a .gridset file somewhere easy to find, such as your Desktop.

      1. Go to Grid Explorer, where your grid sets are listed.
      2. Select the three-line menu in the top-left corner.
      3. Select Share grid sets.
      4. Choose Grid set file on the left.
      5. Select the grid set you want to export, then select Save.
      6. Choose where to save your grid set, give it a name, and select Save.
    2. 2

      Shrink it here

      Drag your saved file into the box above, or select Select a grid set. When it is ready, select Download smaller grid set.

    3. 3

      Check it on a device

      Import the smaller grid set into Grid 3 on your device. Keep your original file as a backup.

      1. Go to Grid Explorer, where your grid sets are listed.
      2. Select the three-line menu in the top-left corner.
      3. Select Add grid set.
      4. Choose Grid set file on the left.
      5. Find the smaller .gridset file you downloaded and follow the on-screen prompts to import it.
      6. Open the imported grid set from Grid Explorer and give the images a brief check before sharing.

    Questions

    What does this tool change?

    Only the pictures stored inside the grid set (for example screenshots and photos). Text, symbols, cell commands, sounds, links and settings are unaffected.

    Will the pictures look worse?

    They should look the same. Every picture is checked against the original after it is made smaller, and if it would look different the original picture is kept instead. Transparency is preserved.

    Why was my grid set rejected?

    Licensed grid sets, usually ending in .gridsetx, cannot be opened by this tool. You will need to get your grid set unlicensed before you can shrink it here.

    Is my grid set uploaded anywhere?

    No. All the work happens on your computer. The grid set is never sent over the internet.

    What if I shrink a grid set that has already been shrunk?

    Pictures that have already been optimised are left unchanged.
