        How to

        From Grid 3 to a corrected grid set in three steps.

        1. 1

          Export your grid set from Grid 3

          In Grid Explorer, select the three-line menu, then Share grid sets and Grid set file. Save the .gridset file somewhere easy to find.

        2. 2

          Check it here

          Drag your file into the box above. For each word that is flagged, choose a correction, or select Accept if it is spelt correctly. Then select Download corrected grid set.

        3. 3

          Import it into Grid 3

          In Grid Explorer, select the three-line menu, then Add grid set. Keep your original file as a backup.

        Questions

        What does it check?

        The words shown on cells, the text cells write and speak, word lists, audio descriptions and tooltips. Each is labelled, so you can tell a mistake on a cell from one in what it says.

        What does it change?

        Only the words you choose to correct. Pictures, sounds, cell commands, styles and settings are untouched.

        Which spelling does it use?

        British English, such as colour and organise.

        Where are my accepted words kept?

        In this web browser, on this computer. Use Export list to save them as a file you can share or import on another computer.

        Is my grid set uploaded anywhere?

        No. All the work happens on your computer. The grid set is never sent over the internet.
